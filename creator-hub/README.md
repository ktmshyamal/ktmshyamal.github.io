# Creator Hub

Quotes, invoices, clients, projects and a content calendar for a creative studio.
Open `index.html` (or the hosted page) and choose "Add to Home Screen" / "Install app".
Data is stored in the browser on each device. Use Settings > Save backup to move it between devices.

`source/` holds the unbundled source files (concatenated in the order: p0-logo, p3a-data, p3-core, p3b-estimate, p4-projects, p4b-followups, p4d-calendar, p4c-clients, p5-invoices, p5b-payments, p6-settings-boot).
